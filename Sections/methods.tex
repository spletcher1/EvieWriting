Fly stocks were maintained on a standard cornmeal-based larval growth medium and in a controlled environment (21C, 60\% humidity) with a 12:12hr light:dark cycle. We controlled the developmental larval density by manually aliquoting 32 ul of collected eggs into individual bottles containing 25-50mL of food at 25C. Following eclosion, mixed sex flies were kept on SY10\% medium (10\% w/v sucrose and 10\% w/v yeast) for 2-4 days until they were sorted by sex and transferred onto chemically defined food or kept on SY10\% food, as needed, for experiments. Experimental flies were flipped to fresh food e/o day until completion of the experiment. Unless otherwise noted, we used mated female flies that were between 7-12 days old for all experiments. Metabolomics Data Processing and Statistical Analysis
Untargeted metabolomics data from the peripheral tissues (bodies) of Drosophila melanogaster were processed using a custom Python pipeline implementing a 2×2 factorial design with Treatment (Light vs. Dark) and Genotype (R2.Chr vs. R2.WCS) as factors. Raw peak area abundances were imported from a compound-by-sample matrix alongside sample metadata. Prior to analysis, metabolites with more than two missing values across all samples were also removed. Remaining abundance values were natural log-transformed to normalize the multiplicative structure of mass spectrometry intensities, after which a per-sample mean-centering step was applied across metabolites to remove global scale differences between sample runs. Residual missing values were then imputed using k-nearest neighbor (KNN) imputation (k = 5), where each metabolite's missing values were estimated from the five most similar metabolites based on the across-sample abundance profile.
For statistical modeling, a separate ordinary least squares (OLS) linear regression model was fit to each metabolite using the formula y ~ Treatment × Genotype, with Dark and R2.WCS as the respective reference levels. This model yielded coefficient estimates and p-values for the main effect of Treatment, the main effect of Genotype, and their interaction term. To control for multiple comparisons across the full panel of metabolites tested, Benjamini–Hochberg (BH) false discovery rate (FDR) correction was applied independently to each of the three coefficient families (Treatment, Genotype, and Treatment × Genotype interaction). Metabolites with an interaction FDR < 0.05 were considered statistically significant and interpreted as those whose response to Treatment differed between the two genotypes—i.e., metabolites exhibiting a non-additive genotype-by-treatment effect.
Pathway enrichment analysis was performed using the FELLA package (v1.x) in R, which leverages the topological structure of the KEGG metabolic network rather than treating pathways as independent gene sets. The KEGG database for Drosophila melanogaster (organism code: dme) was downloaded and compiled into a network graph using buildGraphFromKEGGREST, with global metabolic overview pathways (map01100) excluded to reduce spurious enrichment of highly connected hub nodes. Enrichment was conducted using the diffusion method as the primary approach, supplemented by PageRank for comparison. In the diffusion method, the set of query compounds—KEGG-mapped metabolites with a significant interaction FDR—is used as a seed set on the KEGG compound-enzyme-pathway network; an activation signal propagates outward through the network via a diffusion kernel, and each node (compound, enzyme, reaction, module, or pathway) receives a p-score reflecting the significance of its proximity to the query set. Statistical significance of these p-scores was assessed using the normality approximation, in which background null distributions were pre-computed from 100 permutation iterations during the database build phase and z-scores were derived from these empirical distributions. Pathway nodes with a diffusion p-score < 0.10 were considered enriched.
The background compound set for FELLA was defined as all metabolites in the input data matrix that possessed valid KEGG compound identifiers (format C#####), ensuring that enrichment was evaluated relative to the measurable metabolome rather than the full KEGG database. Significant interaction metabolites with valid KEGG IDs constituted the query set. All FELLA results—including node type, entry name, p-score, and enrichment statistics for both diffusion and PageRank methods—were exported as tabular CSV files for downstream reporting. Pathway results were visualized as bubble plots displaying −log₁₀(p-score) against pathway name, with point size and color encoding enrichment significance. Principal component analysis (PCA) of the preprocessed metabolite matrix was performed to assess sample clustering by treatment and genotype, and volcano plots were generated to visualize the distribution of interaction effect sizes against statistical significance across all tested metabolites.
